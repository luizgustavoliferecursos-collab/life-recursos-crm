# LIFE Recursos CRM Frontend

Frontend Next.js responsivo.

Variáveis na Vercel:
- `NEXT_PUBLIC_API_URL`: URL HTTPS do backend Render, sem barra final.
- `APP_LOGIN_USER`: usuário do login interno.
- `APP_LOGIN_PASSWORD`: senha do login interno.
- `AUTH_SECRET`: segredo aleatório longo usado para assinar a sessão.

Nunca coloque chaves Anthropic, Supabase service role ou credenciais Google no frontend.
